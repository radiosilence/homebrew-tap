# radiosilence/tap

Homebrew formulae and casks for radiosilence projects. Each project's release workflow updates its own file here.

```sh
brew install radiosilence/tap/koan
brew install --cask radiosilence/tap/koan-app
brew install --cask radiosilence/tap/sbr
brew install radiosilence/tap/sift
brew install radiosilence/tap/watchwoman
brew install --cask radiosilence/tap/browser-schedule
```

The per-project taps (`radiosilence/homebrew-<project>`) are retired; their `tap_migrations.json` moves existing installs here on the next `brew update`.
